# 💳 Sistema Inteligente de Detecção de Fraudes Bancárias

## 📌 Visão Geral

Este projeto implementa um sistema de detecção de fraudes bancárias utilizando técnicas de Machine Learning para identificar transações anômalas em tempo real.

O objetivo é fornecer uma solução escalável e confiável que possa auxiliar instituições financeiras na redução de perdas causadas por fraudes.

---

## 🚀 Principais Funcionalidades

- Detecção automática de transações suspeitas
- Pré-processamento dos dados
- Treinamento de modelo de Machine Learning
- Avaliação do desempenho do modelo
- Visualização gráfica dos resultados
- Código modular e de fácil manutenção

---

## 🛠️ Tecnologias Utilizadas

- Python 3.11+
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn
- Plotly

## ▶️ Como Executar

Clone o repositório:

```bash
git clone https://github.com/GBRITO-Tec/fraud-detection-bank.git
```

Entre na pasta:

```bash
cd fraud-detection-bank
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute:

```bash
python src/main.py
```
